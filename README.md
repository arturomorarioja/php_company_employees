# Company Employees
PHP PDO CRUD sample.

## Installation
A file `classes/DBCredentials.php` must be created with the following information:

```php
<?php

Class DBCredentials
{
    protected string $host = '<your_host_name>';
    protected string $dbname = 'company';
    protected string $user = '<your_database_username>';
    protected string $password = '<your_database_password>';
}
```
